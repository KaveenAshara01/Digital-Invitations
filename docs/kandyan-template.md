# Kandyan vows

Preview `/templates/kandyan-vows`, then choose Make this invitation. Change names and wording in Content, date and venue in Event, and colors and typography in Style. Abhaya Libre supports Unicode Sinhala and Latin text. Add photos in Media; Gallery is enabled by default and follows the order of uploaded media. Media saves immediately; save the draft after changing other settings. Uploads require working R2 credentials and CORS configuration as described in storage.md.

The original decorative illustration is bundled at `public/templates/kandyan/couple.png`; customer photos use the existing private media pipeline. Lotus ornaments are original SVG code in the hero component. The font and its license are in `public/fonts`.
